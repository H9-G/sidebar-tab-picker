# Sidebar Tab Picker

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | **Deutsch**

Lege fest, welche Tabs die rechte Seitenleiste zeigt und in welcher Reihenfolge. Ausgeblendete Tabs bleiben auch nach einem Neustart ausgeblendet.

## Verwendung

1. Öffne **Einstellungen → Sidebar Tab Picker**. Dort steht jeder Tab, der schon einmal in der rechten Seitenleiste war: Rückverweise, Gliederung, Tabs anderer Plugins und so weiter.
2. Schalte einen Tab **aus**, um ihn auszublenden, und **ein**, um ihn wieder anzuzeigen.
3. **Ziehe** einen Tab in der Liste, um die Reihenfolge zu ändern.
4. Beide Änderungen wirken sofort in der Seitenleiste.

- Tabs, die du in der Seitenleiste von Hand öffnest, schließt oder verschiebst, werden in der Liste übernommen.
- Beim Start von Obsidian werden Tabs, die andere Plugins von selbst öffnen, wieder geschlossen, wenn sie ausgeschaltet sind.
- **Seitenleiste einlesen** fügt die gerade offenen Tabs hinzu, **Alle anzeigen** schaltet alle ein. Mit der Löschtaste einer Zeile vergisst das Plugin diesen Tab, etwa nachdem du sein Plugin entfernt hast.
- Einstellungen und Befehle gibt es auf Englisch, Japanisch, vereinfachtem Chinesisch, traditionellem Chinesisch, Koreanisch, Spanisch, Französisch und Deutsch. Die Sprache folgt beim ersten Start Obsidian und lässt sich in den Einstellungen ändern.

## Gut zu wissen

- Ein ausgeblendeter Tab wird wirklich geschlossen und beim Anzeigen neu geöffnet. Seine Scrollposition und Ähnliches werden dabei zurückgesetzt. Ändert sich die Reihenfolge, werden nur die Tabs ab dem ersten falsch platzierten neu geöffnet.
- Nur die rechte Seitenleiste wird verwaltet.

## Netzwerknutzung

Keine. Das Plugin arbeitet offline und sammelt keine Daten.
