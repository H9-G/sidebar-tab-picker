# Sidebar Tab Picker

Choisissez les onglets affichés dans la barre latérale droite, et leur ordre. Les onglets masqués le restent après un redémarrage.

## Utilisation

1. Ouvrez **Réglages → Sidebar Tab Picker**. Chaque onglet déjà apparu dans la barre latérale droite y figure : rétroliens, plan, onglets d'autres plugins, etc.
2. **Désactivez** un onglet pour le masquer, **activez-le** pour l'afficher de nouveau.
3. **Faites glisser** un onglet dans la liste pour changer l'ordre.
4. Les deux changements s'appliquent immédiatement dans la barre latérale.

- Les onglets ouverts, fermés ou déplacés à la main dans la barre latérale sont aussi suivis dans la liste.
- Au démarrage d'Obsidian, les onglets que d'autres plugins ouvrent d'eux-mêmes sont refermés s'ils sont désactivés.
- **Lire la barre latérale** ajoute les onglets ouverts en ce moment, et **Tout afficher** les active tous. Le bouton de suppression d'une ligne oublie cet onglet, par exemple après avoir retiré son plugin.
- Les réglages et les commandes existent en anglais, japonais, chinois simplifié, chinois traditionnel, coréen, espagnol, français et allemand. La langue suit celle d'Obsidian au premier lancement et peut être changée dans les réglages.

## Bon à savoir

- Un onglet masqué est réellement fermé, puis rouvert quand il est affiché : sa position de défilement et les états similaires sont réinitialisés. Quand l'ordre change, seuls les onglets à partir du premier mal placé sont rouverts.
- Seule la barre latérale droite est gérée.

## Utilisation du réseau

Aucune. Le plugin fonctionne hors ligne et ne collecte aucune donnée.
