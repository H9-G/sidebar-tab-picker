# Sidebar Tab Picker

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

選擇右側邊欄要顯示哪些分頁，以及它們的順序。隱藏的分頁在重新啟動後仍會維持隱藏。

## 使用方式

1. 開啟 **設定 → Sidebar Tab Picker**。這裡列出曾出現在右側邊欄的所有分頁：反向連結、大綱、其他外掛的分頁等。
2. 關閉某個分頁即可**隱藏**它，開啟即可再次**顯示**。
3. 在清單中**拖曳**分頁即可調整順序。
4. 兩種變更都會立即反映到側邊欄。

- 在側邊欄中手動開啟、關閉或移動分頁，也會同步到清單。
- Obsidian 啟動時，其他外掛自動開啟的分頁若已設為關閉，會再次關掉。
- 「讀取側邊欄」會加入目前開啟的分頁，「全部顯示」會開啟所有分頁。每一列的刪除按鈕可將該分頁從清單移除（例如刪除其外掛之後）。
- 設定與指令支援英文、日文、簡體中文、繁體中文、韓文、西班牙文、法文與德文。首次使用時跟隨 Obsidian 的語言，之後可在設定中變更。

## 注意事項

- 隱藏的分頁會真的被關閉，顯示時重新開啟，因此捲動位置等狀態會被重設。調整順序時，只會重新開啟從第一個位置不對的分頁開始的那些分頁。
- 只處理右側邊欄。

## 網路使用

無。外掛離線運作，不收集任何資料。
