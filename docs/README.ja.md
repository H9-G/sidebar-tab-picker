# Sidebar Tab Picker

[English](../README.md) | **日本語** | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

右サイドバーに表示するタブと、その並び順を選べます。隠したタブは、再起動しても隠れたままです。

## 使い方

1. **設定 → Sidebar Tab Picker** を開きます。右サイドバーに出たことのあるタブ（バックリンク、アウトライン、ほかのプラグインのタブなど）が並んでいます。
2. タブを**オフ**にすると隠れ、**オン**にするとまた表示されます。
3. 一覧のタブを**ドラッグ**すると、並び順が変わります。
4. どちらも、すぐに右サイドバーに反映されます。

- サイドバーで手でタブを開く・閉じる・動かすと、一覧にも反映されます。
- Obsidianの起動時に、ほかのプラグインが勝手に開いたタブも、オフにしてあれば閉じます。
- 「サイドバーを読み込む」で今開いているタブを加え、「すべて表示」で全部オンにできます。行の削除ボタンで、そのタブを一覧から消せます（プラグインを削除したあとなど）。
- 設定とコマンドは、英語、日本語、簡体字中国語、繁体字中国語、韓国語、スペイン語、フランス語、ドイツ語で表示できます。最初はObsidianの言語に合わせ、設定で変更できます。

## 注意

- 隠したタブは実際に閉じ、表示するときに開き直します。スクロール位置などはリセットされます。並び順を変えたときは、最初に位置がずれたタブから後ろだけを開き直します。
- 対象は右サイドバーだけです。

## ネットワークの利用

ありません。オフラインで動き、データも集めません。
