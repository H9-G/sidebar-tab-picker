# Sidebar Tab Picker

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **한국어** | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

오른쪽 사이드바에 어떤 탭을 어떤 순서로 보여줄지 고를 수 있습니다. 숨긴 탭은 다시 시작해도 숨겨진 채로 남습니다.

## 사용 방법

1. **설정 → Sidebar Tab Picker**를 엽니다. 오른쪽 사이드바에 나온 적이 있는 탭(백링크, 개요, 다른 플러그인의 탭 등)이 모두 나열됩니다.
2. 탭을 **끄면** 숨겨지고, **켜면** 다시 표시됩니다.
3. 목록에서 탭을 **끌어서** 순서를 바꿉니다.
4. 두 변경 모두 사이드바에 바로 반영됩니다.

- 사이드바에서 직접 탭을 열거나 닫거나 옮기면 목록에도 반영됩니다.
- Obsidian을 시작할 때 다른 플러그인이 스스로 연 탭도, 꺼 두었다면 다시 닫습니다.
- '사이드바 읽기'는 지금 열려 있는 탭을 추가하고, '모두 표시'는 모든 탭을 켭니다. 각 행의 삭제 버튼으로 그 탭을 목록에서 지울 수 있습니다(플러그인을 삭제한 뒤 등).
- 설정과 명령은 영어, 일본어, 중국어 간체, 중국어 번체, 한국어, 스페인어, 프랑스어, 독일어로 표시됩니다. 처음에는 Obsidian의 언어를 따르고, 설정에서 바꿀 수 있습니다.

## 참고

- 숨긴 탭은 실제로 닫았다가 표시할 때 다시 엽니다. 그래서 스크롤 위치 등은 초기화됩니다. 순서를 바꾸면 처음으로 위치가 어긋난 탭부터 뒤쪽만 다시 엽니다.
- 오른쪽 사이드바만 다룹니다.

## 네트워크 사용

없습니다. 오프라인으로 동작하며 데이터를 수집하지 않습니다.
