# Sidebar Tab Picker

[English](../README.md) | [日本語](README.ja.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

选择右侧边栏显示哪些标签以及它们的顺序。隐藏的标签在重启后仍保持隐藏。

## 使用方法

1. 打开 **设置 → Sidebar Tab Picker**。这里列出了出现过在右侧边栏中的所有标签：反向链接、大纲、其他插件的标签等。
2. 关闭某个标签即可**隐藏**它，打开即可再次**显示**。
3. 在列表中**拖动**标签即可调整顺序。
4. 两种更改都会立即反映到侧边栏。

- 在侧边栏中手动打开、关闭或移动标签，也会同步到列表。
- Obsidian 启动时，其他插件自动打开的标签如果已被关闭，会再次关掉。
- “读取侧边栏”会加入当前打开的标签，“全部显示”会打开所有标签。每一行的删除按钮可以从列表中移除该标签（例如删除其插件之后）。
- 设置和命令支持英语、日语、简体中文、繁体中文、韩语、西班牙语、法语和德语。首次使用时跟随 Obsidian 的语言，之后可在设置中更改。

## 注意事项

- 隐藏的标签会被真正关闭，显示时重新打开，因此滚动位置等状态会被重置。调整顺序时，只会重新打开从第一个位置不对的标签开始的那些标签。
- 只处理右侧边栏。

## 网络使用

无。插件离线工作，不收集任何数据。
